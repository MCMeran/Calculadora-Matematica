# 🧮 CalculadoraMatematica

Una aplicación de consola en **Java** que permite realizar operaciones matemáticas básicas entre dos números.  
Incluye un menú interactivo, validación de errores y está diseñada siguiendo buenas prácticas de programación.

---

## 📋 Características

- Operaciones disponibles:
  - ➕ Suma  
  - ➖ Resta  
  - ✖️ Multiplicación  
  - ➗ División (con control de división por cero)
- Menú interactivo con `switch`
- Bucle `do-while` para mantener el programa activo
- Entrada de datos mediante `Scanner`
- Comentarios descriptivos y documentación JavaDoc

---

## ⚙️ Requisitos

- **Lenguaje:** Java 8 o superior  
- **Entorno:** Consola o IDE (Eclipse, IntelliJ, NetBeans)  
- **Entrada:** Usuario mediante teclado  
- **Salida:** Resultados en consola  

---
